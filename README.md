# cartlife_src (fork)

A fork of the [Cart Life](https://en.wikipedia.org/wiki/Cart_Life) source by Richard Hofmeier, written in Adventure Game Studio (AGS).

**What I'm doing:**
- Cleaning up and linting the AGS scripts, one branch at a time
- Later: a Rust reimplementation that runs the game as a native executable

The original README is at [README.original.md](README.original.md). See [LICENSE.md](LICENSE.md) for the license. The third-party music and the Hooge font are excluded from it.
